Pubblica su GitHub

Il sito legge i contenuti da src/content.json. "Pubblica" salva quel file nel repository con un commit; se il sito è collegato a Vercel/Netlify/Cloudflare si aggiorna da solo in 1-2 minuti.

Il token resta solo in questa scheda del browser. Senza token (o password) nessuno può modificare il sito.

Password admin

La password sblocca il token GitHub da qualsiasi dispositivo, dal lucchetto in basso a destra del sito. Il token viene salvato nel repository solo cifrato con questa password: sceglila lunga (una frase) e non riusarla altrove.
